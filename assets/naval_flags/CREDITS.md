# Naval Flag Image Credits

## International Code of Signals (ICS) Flags

The SVG files in this directory depict the 26 letter flags (Alfa-Zulu) and
10 numeral flags (Zero-Niner) of the International Code of Signals (ICS),
as standardized by the International Maritime Organization (IMO).

### Source

SVG files downloaded from Wikimedia Commons. The ICS flag patterns are a
published international standard and are not subject to copyright; the
Wikimedia-hosted SVGs are released to the public domain.

### File naming

| Range | Pattern | Example |
|-------|---------|---------|
| Letters A-W, Y-Z | `ICS_<Phonetic>.svg` | `ICS_Alfa.svg` |
| Letter X | `ICS_X-ray.svg` | — |
| Numerals 0-9 | `ICS_<Word>.svg` | `ICS_Zero.svg`, `ICS_Niner.svg` |

### Colors

| Code | Color  | Hex     |
|------|--------|---------|
| W    | White  | #FFFFFF |
| B    | Blue   | #003399 |
| R    | Red    | #CC0000 |
| Y    | Yellow | #FFD700 |
| K    | Black  | #111111 |
